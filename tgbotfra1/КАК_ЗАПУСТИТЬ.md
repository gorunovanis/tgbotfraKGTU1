# Как запустить FoodApp (PHP + MySQL)

Проект работает **на PHP**: статика (`static/app/`), API (`php/api.php` через `.htaccess`). Данные в **MySQL**. Вход — **регистрация на сайте** (email и пароль), сессия PHP в cookie.

## Требования

- PHP 7.4+ с расширениями `pdo_mysql`, `session`, `json`
- MySQL / MariaDB
- **HTTPS** на продакшене (для cookie сессии)

## Структура

- `static/index.html` — лендинг (приглашение и кнопки на регистрацию)
- `static/app/` — приложение (`index.html`, `app.js`, `style.css`)
- `php/api.php` — API
- `php/config.local.php` — создайте из `config.local.php.example`: **BASE_URL** (URL сайта с путём, например `https://домен.ru/tgbotfra`), **DB_***
- `schema_mysql.sql` — схема БД: все таблицы с префиксом **`ff_`** (`ff_users`, `ff_meals`, `ff_water`, …)
- `schema_migration_rename_tables_fra_to_ff.sql` — переименование старых имён `*_fra` → `ff_*` (если база создавалась раньше)
- `schema_migration_site_auth.sql` — добавление `email` / `password_hash` к старой `ff_users` (не нужна после свежего `schema_mysql.sql`)

## Установка

1. Залейте файлы на хостинг, в корне должен быть `.htaccess`, запросы к `/profile`, `/auth/login` и т.д. переписываются в `php/api.php`.
2. Создайте БД, выполните `schema_mysql.sql` (или миграцию, если таблица уже есть).
3. Создайте `php/config.local.php` с **BASE_URL** (тот же путь, по которому открывается сайт) и доступом к MySQL.
4. Откройте в браузере `https://ваш-домен/.../static/app/` — регистрация и вход.

## Проверка

- `php/check_setup.php` — конфиг и таблицы (потом удалите с сервера).
- `php/debug_headers.php` — есть ли сессия после входа.

## Сессия не держится

В `config.local.php` или `.env` укажите **BASE_URL** как корень сайта с путём до папки проекта, **без** `/static/app/index.html` (например `https://домен.ru/tgbotfra`). Раньше из ошибочного полного URL к странице ломался `path` у cookie; сейчас URL нормализуется в PHP, а cookie сессии выставляется с `path=/`.

## AI и фото блюда

- Умные подсказки и оценка КБЖУ по названию/«по фото» встроены в **`static/app/app.js`** (логика в коде в браузере, **без API-ключей**, без загрузки нейромоделей из интернета).
- **Штрих-код** запрашивает **Open Food Facts** (ключ не нужен; нужен интернет у клиента). Если продукт не в базе — введите блюдо вручную.
