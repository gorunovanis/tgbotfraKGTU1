# FitHealth39 (`rayXlain.github.io`)

Прототип веб-приложения с поиском (Fuse.js) и набором примеров подключения к базе данных MySQL (`kuzbassmeg`).

## Основные файлы

- `index.html`, `style.css`, `script.js` — клиентский интерфейс.
- `database.sql`, `database_setup.md` — SQL-схема и инструкция по настройке БД.
- `CONNECTION_README.md` — примеры и настройка подключения к MySQL.
- `db_connection.php`, `db_connection.js`, `db_connection.py` — модули подключения к БД для PHP, Node.js и Python.
- `api_example.php`, `api_example.js`, `test_connection.php` — примеры API и проверки соединения.
